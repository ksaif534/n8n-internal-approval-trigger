# n8n Approval Trigger Workflows

This directory contains two n8n workflow JSON files:

- `internal-form-request-approval.json`: This workflow is designed to handle internal form requests that require approval. It likely triggers when a new form submission is made and initiates an approval process.

- `update-approval-status-send-confirmation.json`: This workflow is responsible for updating the status of an approval request and sending a confirmation. It probably gets triggered after an approval decision is made (approved or rejected) and then communicates the outcome.
